# 🚀 Stockora

A full-stack stock trading and portfolio management platform inspired by modern brokerage applications. Built with the MERN stack, Stockora provides secure authentication, portfolio tracking, order management, and an interactive dashboard experience.

## 🌐 Live Demo

https://stockora-frontend.onrender.com/

## 💻 Source Code

https://github.com/AdityaSinha2005/Stockora

---

## 📌 Features

### Authentication & Security

* User Registration & Login
* Password Hashing using BCrypt
* JWT-Based Authentication
* Protected Routes
* Secure Session Management

### Trading Dashboard

* Holdings Management
* Positions Tracking
* Order Management
* Funds Overview
* Portfolio Analytics
* Watchlist Monitoring

### User Experience

* Responsive Design
* Modern Dashboard UI
* Component-Based Architecture
* Fast Client-Side Navigation

---

## 🏗️ Architecture

```text
React Frontend
       ↓
Axios HTTP Requests
       ↓
Node.js + Express Backend
       ↓
JWT Authentication Middleware
       ↓
MongoDB Atlas
```
